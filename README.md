# web-apps

Col·lecció de petites aplicacions web de **surikata3k** que funcionen directament al navegador (HTML + CSS + JavaScript).
🔗 **En línia:** [https://surikata3k.github.io/web-apps/](https://surikata3k.github.io/web-apps/)


| App | Carpeta | Descripció |
|---|---|---|
| Dits Màgics | [`dits_magics/`](dits_magics/) | Mecanografia en català per a nens i nenes |
| Hores de RA | [`calc_hours_ra/`](calc_hours_ra/) | Planificador i distribuïdor d'hores de RA |
| PassForge | [`passgen/`](passgen/) | Generador de contrasenyes |
| Vaultless Password | [`vaultless/`](vaultless/) | Contrasenyes deterministes a partir d'una clau mestra |
| Analitzador de contrasenya | [`password_info/`](password_info/) | Avalua la força d'una contrasenya |
| Calculadora d'entropia | [`password_calculator/`](password_calculator/) | Combinacions i entropia de contrasenyes |

La pàgina d'inici (`index.html` + `styles.css`) enllaça totes les apps.
